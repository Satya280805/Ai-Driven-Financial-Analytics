Isolation Forest
Isolation Forest is an unsupervised machine learning algorithm designed to identify observations that are different from the majority of the dataset.

The model uses:

• Amount
• Budget
• Quantity
• Tax Amount
• Budget Variance
• Budget Utilization

A detected anomaly represents an unusual financial pattern and should be investigated further. It should not automatically be interpreted as fraud.
